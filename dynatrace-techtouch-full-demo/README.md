# Dynatrace×テックタッチ 本格デモ（イメージ）

本格デモ（15〜20分）を実機で作るための、画面の流れのイメージです。SEはこのデモと構築依頼書（シナリオ。別途共有）をもとに、実機のDynatraceとテックタッチで同じ流れを作ります。

- 流れ：運用チームの一日（架空）。新任者の立ち上がり → 毎朝の確認 → 問い合わせ対応（デモ①）→ 障害の一次対応（デモ②）→ 原因の深掘り → 再発防止と自動化（デモ③）→ 定着の見える化 → 振り返り
- 画面・人物・サービス名・手順・数値はすべて架空です。実際の製品画面や連携動作を示すものではありません（画面上にも常時表示）。
- 監視画面はDynatraceの画面イメージ（左のDock、アプリヘッダー、配色）を踏襲した架空画面です。場面7はテックタッチ管理画面のイメージ（架空）です。
- `index.html` 1ファイルで動きます。外部への通信はありません。

## 使い方

1. `index.html` をブラウザ（Chrome／Edge推奨）で開く
2. 右のパネルのボタンで1ステップずつ進む。左の画面を直接操作しても進みます（違う値や順番を選ぶと、ガイドが案内します）
3. 上部の「業務の流れ」で場面を切り替えられます

| 操作 | キー |
|---|---|
| 次へ／戻る | → ／ ← |
| 場面の切り替え | 1〜8（8は振り返り） |
| 進行メモ（話すこと・想定問答） | N |
| この場面を最初から | R |

URL末尾に `#s1`〜`#s8` を付けると、その場面から開きます。

## 決め事（10/1の意見交換から引き継ぎ）

- Dynatrace＝観測、テックタッチ＝介入。Dynatrace内で完結する支援（根本原因の分析、調査ガイドの推薦、Dynatrace Assist）は、Dynatraceの機能として見せます。AI Hubは社内資料の側を補う構想です。
- 削減率などの効果の数値は示しません。確かめ方は自力完了率・所要時間・依頼件数・再実行です。場面7の数値も架空で、効果を示すものではありません。
- ガイドは「よく止まる作業」に絞り、持ち主・見直し時期・Dynatraceの画面更新時の点検手順を決めます。

## 画面デザインの根拠

- 配色・角丸・影：Dynatrace公式デザイントークン `@dynatrace/strato-design-tokens` 1.7.1（Apache-2.0）の値（`dynatrace-techtouch-demo` と同じ）。
- Dynatraceのロゴ、アイコン画像、専用フォントは使っていません。アイコンは汎用の図形です。
- 画面の構成・項目名（問題画面のタブ、ひな型、ワークフローの設定項目など）、DQLの例、Dynatrace Assistの回答の例は架空です。実機の画面・操作は、構築時に確かめて合わせます。
