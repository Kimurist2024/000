# Dynatrace×テックタッチ 構想デモ

2026年10月1日の意見交換用資料（v2・17枚）のp.11〜13「デモ①／②／③」を、**ある運用担当者（架空）の一日の業務**として1本につないだ、その場で操作できるHTMLデモです。

- 流れ：問い合わせを受ける → 担当サービスの状況を確認（デモ①）→ 障害の一次確認と連絡（デモ②）→ 再発に備えてダッシュボードを作る（デモ③）→ 振り返り
- 画面・サービス名・手順・数値はすべて架空です。実際の製品画面や連携動作を示すものではありません（画面上にも常時表示）。
- 監視画面はDynatraceの画面イメージ（左のDock、アプリヘッダー、ツールバー、配色）を踏襲した架空画面です。テックタッチ（青）とAI Hub（紫）は、その上に重なるオーバーレイとして表示します。
- デモはテックタッチ（DAP）中心です。仮説2（AI Hubの理解支援）は専用デモを持たず、p.8の支援案で説明します。
- `index.html` 1ファイルで動きます。外部への通信はありません（ネットワークのない会議室でも表示できます）。

## 使い方

1. `index.html` をブラウザ（Chrome／Edge推奨）で開く
2. 右のテックタッチのパネルのボタン（「ガイドを開始」「次へ」「ログを開く」など）で1ステップずつ進む。左の画面を直接操作しても進みます
3. 上部の「業務の流れ」で章を切り替えられます。章の終わりごとに止めて「伺いたいこと」を質問できます

| 操作 | キー |
|---|---|
| 次へ／戻る | → ／ ← |
| 章の切り替え | 1〜4（4は振り返り） |
| 進行メモ（発表者用、既定は非表示） | N |
| この章を最初から | R |

- 表示色は「表示：自動／ライト／ダーク」で切り替えられます。スライドと同じ見た目にするには「ライト」を選びます（選択はブラウザに保存されます）。
- URL末尾に `#c1`〜`#c4` を付けると、その章から開きます。
- Dynatraceに合わせて画面内の文字は14pxです。会議室で小さく感じる場合はブラウザの拡大（Ctrl＋「+」）で調整できます。

## 動画版

`video/dynatrace-techtouch-demo.mp4`（3分35秒、1920×1080、H.264、音声なし）。PowerPointに埋め込んで再生できます。

- 構成：表紙 → 今日の業務の流れ（全体像）→ 第1章 → 第2章 → 第3章 → 振り返り → 最初の一歩。各章の最後に「伺いたいこと」を表示します。
- 画面下の字幕に、操作の説明と「構想デモ｜画面・サービス名・手順・数値は架空で…」の注記を常に表示します。
- 字幕の文面と操作の順番は `video/record.js` の「台本」にあります。デモや字幕を直したら、次の手順で作り直せます。

```sh
cd video
npm install                      # 撮影用フォント（Noto Sans JP、Roboto）
NODE_PATH="$(npm root -g)" FFMPEG=/path/to/ffmpeg node record.js
```

必要なもの：Playwright（Chromium）、libx264 を含む ffmpeg。撮影時は中国語の字形が混ざらないよう、日本語フォントを Noto Sans JP に固定しています（HTMLを会議で開く場合は游ゴシック／ヒラギノで表示されます）。

| 項目 | 根拠 |
|---|---|
| 配色・角丸・影・文字サイズ（ライト／ダーク） | Dynatrace公式デザイントークン `@dynatrace/strato-design-tokens` 1.7.1（Apache-2.0、npm、2026-09-18更新）の値。例：背景 `#f9f9fa`、本文 `#2f2f4f`、プライマリ `#464cce`、入力欄の角丸 6px |
| 日本語表記（時間枠、過去 24 時間、セグメント、適用） | 公式UIコンポーネント `@dynatrace/strato-components` 3.14.2（Apache-2.0）の `lang/ja.json` |
| 左のDock（ホーム・検索・アプリ、下部にDockを隠す・サポート・ユーザー） | [Navigate the Dynatrace platform](https://docs.dynatrace.com/docs/discover-dynatrace/get-started/dynatrace-ui) |
| サービス画面の構成（応答時間・失敗率・スループット、過去期間との比較） | [Services app](https://docs.dynatrace.com/docs/shortlink/services-app) |
| 問題の詳細（概要・影響範囲・ログ・イベント） | 10/1資料 p.12 の構成に合わせた架空画面。Dynatraceの問題画面の実際のタブ構成とは照合していません |

- Dynatraceのロゴ、アイコン画像、専用フォント（DynatraceFlow）は使っていません。アイコンは汎用の図形です。
- Dockのアプリ名（ダッシュボード、サービス等）、ホーム画面、ダッシュボード一覧は架空の表記です。実際の日本語表示名は確認していません。

## 整理メモの決め事の反映

- Dynatrace＝観測、テックタッチ＝介入。テックタッチの価値は「介入」に置く
- デモはDAP中心。社内手順・連絡先は架空で、お客様の実際の手順に置き換える前提
- AI欄は事前作成の例文であることを明記し、原因は断定しない
- Dynatrace内で完結する説明はDynatraceの既存AI支援（Dynatrace Assist）を優先し、AI Hubは社内資料側を補う
- 削減率などの効果の数値は示さない。ガイドの完了率だけで判断せず、作業の結果で確かめる
- 顧客向けの表現（「伺っていること」等）と、Dynatrace勉強会資料（CONFIDENTIAL）を引用しない扱いを守る
- 游ゴシック（Macではヒラギノ）で表示し、言語は日本語（`lang="ja"`）に指定して中国語の字形が混ざらないようにする

## 本番前に確認が必要なこと

- **テックタッチの製品機能で再現できるか**：次の動きは構想の表現です。製品でどこまで実現できるかは確認が必要です。
  - 画面に応じたガイド一覧（おすすめの表示）
  - 問題画面を開いたときのポップアップ
  - 「?」のツールチップ（社内の指標定義・優先度の基準）
  - 違う値を選んだときの選び直しの案内、順番を飛ばしたときの案内
  - ガイドの画面から離れたときの案内
- **このデモ用に新しく書いた架空の内容**（お客様に見せる前に確認してください）：
  - 想定の人物像（Dynatraceを使うのは月に数回）
  - 社内の目安（平均応答時間 500 ms 以下）、優先度の基準（高・中・低）
  - ログの文面、連絡先・連絡内容の例、一次確認の記録、ガイドの所要の目安（5分・10分）
  - 専門家の助言・承認の文面、ダッシュボード名・所有者
  - デモ③のAI Hub欄の文章
- p.13の画像では「DQLそのものの**生成・実行**は…」、このデモでは「DQLそのものの**生成・説明**は、Dynatraceの既存機能（Dynatrace Assist）の利用状況も含めて確認します」としています。検証台帳で確認済みなのは「DQLの生成・説明」です。どちらに揃えるか決める必要があります。
- 監視画面は公開情報をもとに作っています。トライアル環境の実画面（配置・項目名）とは照合できていません（この作業環境からdynatrace.comに接続できなかったため）。
- p.11〜13の画像とは表記や見せ方が一部異なります（「時間枠：過去 24 時間」などDynatraceの日本語表記に合わせたため。デモ②の確認理由はステップごとに出し分け、吹き出しは色の約束に合わせて青）。
