# IT運用 × テックタッチ　ServiceNow・Splunk（ITSI・サーチとレポート）をまたぐ手順のデモ（イメージ）

架空のA社の IT運用を題材にしたイメージデモです。監視は Zabbix・JP1、起票と記録は ServiceNow、影響と事実の確認は Splunk Cloud（ITSI と サーチとレポート）という構成で、ツールをまたぐ社内の手順をテックタッチのガイドで画面の上に置きます。

- **前半：夜間の一次切り分け**（10月21日 22:41〜、夜間当番）ServiceNow → ITSI（Episode Review → Service Analyzer → Deep Dive）→ 保存済みサーチ → ServiceNow
- **後半：月1回の稼働統計**（11月4日 9:32〜、運用基盤チーム）ServiceNow → レポート → ServiceNow

企業・人物・サービス・ホスト・チケット番号・手順・数値はすべて架空で、特定の企業を題材にしたものではありません。ドメインは文書用の予約名（`.example`）です。

## 中身

| ファイル | 内容 |
|---|---|
| `demo/index.html` | デモ本体（1ファイル。ブラウザで開くだけで動きます） |
| `demo/video/itops-servicenow-splunk-techtouch-demo.mp4` | 自動操作で撮った動画（1920×1080） |
| `demo/src/` | デモの元のコード（React・Splunk 公式 UI ツールキット）と自動テスト |
| `demo/video/record.js` | 動画を撮る台本 |

操作：右下のテックタッチの一覧からガイドを再生し、吹き出しのとおりに画面を押します。画面の下の進行バーの「このステップを進める」か → キーでも進みます。キー操作は → 次へ／← 戻る／1〜9 場面／0 振り返り／N 進行メモ／R この場面を最初から。

## 画面の手本（瓜二つにするために確かめたもの）

| 画面 | 手本 | 決めたこと |
|---|---|---|
| ServiceNow | 公式ドキュメントの画面写真（Next Experience の Polaris テーマ。インシデントの一覧・フォーム・メモ・アクティビティ） | 上部のバー、フォームの見出し帯とボタン、入力欄、メモ欄（「作業メモ」のチェックと「投稿」）、アクティビティの色を、写真から測った値に合わせた |
| Splunk ITSI | Splunk 公式の公開リポジトリにある ITSI 5.0 の画面写真（2026年9月、新しいナビゲーション・ダーク） | Splunk Cloud Platform 10.4.2604 以降は新しいナビゲーション（上のヘッダー＋左の縦のメニュー）で、元の表示には戻せない（Splunk のリリースノート）。そのため ITSI 5.0 の配置に合わせた。ITSI 5.0 では詳細の「Impact」タブが無く、「Events Timeline」で順番を見る |
| サーチとレポート | Splunk 公式の画面写真（サーチ画面・ダーク）と、Splunk 公式の部品（時間範囲ピッカー `@splunk/react-time-range`、サーチの入力欄 `@splunk/react-search`） | 時間範囲の一覧は Splunk 公式の部品をそのまま使い、Splunk Web と同じ仕組み（翻訳の関数）で日本語にした |
| テックタッチ | テックタッチの製品の表示（ServiceNow 上で動かしたときの見た目） | 吹き出し（「1 > 2 > STEP 3」・ガイドを停止・緑の「次へ」）、赤い枠の注意書き、テンプレートの挿入、再生中の表示、終了の通知、自動処理中の表示の色と形を、製品の表示から測った値に合わせた |

### 実画面で確かめる必要があるもの

日本語の表記は、日本語の公式ドキュメントと日本語画面の記事で確かめたものを使いました。出典が見つからなかったものは次のとおりで、実画面で確かめて直します。

- **ServiceNow**：ナビゲーションの「すべて／お気に入り／履歴／ワークスペース」、「検索」、「投稿」、「アクティビティ」、「追加コメント (顧客に表示)」の括弧の部分、タブ名、「ディスカッション」「応答」、一覧の文言、タスクの状態（オープン／作業中／クローズ (完了) など）。確認済みの表記（ServiceNow の日本語ドキュメント、2019〜2021年）：問い合わせユーザー、受付手段、ステータス、影響、緊急度、優先度、アサイン先グループ、アサイン先、概要説明、作業メモ、ウォッチリスト、作業メモリスト、状態の「新規／処理中／保留中／解決済み／クローズ済み／キャンセル」。ServiceNow は Washington DC 版から日本語の用語を見直しているため、現行版での表記は要確認。
- **Splunk（サーチとレポート）**：「テーブルビューの作成」、ジョブの行（件のイベント、イベントサンプリングなし、ジョブ）、時間範囲の「過去 15 分間／過去 60 分間／過去 4 時間／過去 30 日間／今日／前月」（確認済みは「過去 24 時間／過去 7 日間／全時間」と、数字の前後に半角スペースを入れる書き方）、レポートの一覧の列名と説明文、「編集／その他のアクション」、結果のエクスポートの画面の文言。
- **Splunk（ITSI）**：ITSI の画面が日本語になるか（このデモは英語のまま）。Deep Dive は画面写真が見つからず、公式ドキュメントの説明（レーン・しきい値の帯）から組んだ。新しいナビゲーションの左のメニューのアイコンの割り当て（Service Analyzer と Alerts and Episodes 以外）と、Splunk Cloud のヘッダーの製品名の表記。
- **テックタッチ**：ServiceNow と Splunk のようにドメインが違う画面で、ガイドをどうつなぐか（このデモは、ツールごとにガイドを分け、リンクで開いた先で続きを再生する想定）。Zabbix・JP1 は図だけで、Web 画面であれば同じ仕組みで載る想定（要検証）。

## 作り直し方

```
cd demo/src
npm install
python3 build.py                     # ../index.html を書き出す（DEMO_FORBID に公開してはいけない語をカンマ区切りで入れると、含まれていないかを確かめる）
NODE_PATH="$(npm root -g)" node test_demo.js   # 自動テスト（Playwright）

cd ../video
npm install
NODE_PATH="$(npm root -g)" FFMPEG=/path/to/ffmpeg node record.js   # 動画（実時間で録画して MP4 にする）
```

## ライセンス・注記

- 画面の部品に Splunk 公式の UI ツールキット（`@splunk/react-ui`・`@splunk/react-time-range`・`@splunk/react-search` ほか、Apache-2.0）を使っています。ServiceNow の画面は CSS で組んだ画面イメージで、ServiceNow の部品やコードは含みません。
- ServiceNow・Splunk は各社の商標です。このデモは各社の製品の実画面ではなく、各社が作ったものでもありません。
